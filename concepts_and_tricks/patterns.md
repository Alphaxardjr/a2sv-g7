# 🟢 Problem-Solving Patterns

## Pattern 1 — Set / Uniqueness
**Clues:**
- distinct  
- unique  
- duplicates  
- different characters  
- pangram  
- count types  

**Tool:** `set()`  

**Examples:**
- Boy or Girl  
- Pangram  
- count distinct numbers  

---

## Pattern 2 — Frequency Counting
**Clues:**
- how many times  
- most frequent  
- pairs with same value  
- anagrams  
- duplicates count  
- occurrences  

**Tool:** `Counter` / `dict`  

**Examples:**
- most common element  
- number of equal pairs  
- grouping  

---

## Pattern 3 — Sorting + Greedy
**Clues:**
- minimize / maximize  
- choose best  
- largest/smallest first  
- coins/money  
- differences  

**Tool:** `sort()`  

**Examples:**
- Twins (coins)  
- minimize difference  
- greedy picks  

---

## Pattern 4 — Two Pointers (VERY common)
**Clues:**
- from ends  
- pairs  
- subarray  
- sorted array  
- sum equals target  
- windows  

**Tool:** `l, r`  

**Examples:**
- Sereja and Dima  
- pair sum  
- sliding window  

---

## Pattern 5 — Prefix Sum
**Clues:**
- many range sums  
- queries  
- subarray sum  
- sum between l and r  

**Tool:** prefix array  

---

## Pattern 6 — Brute Force (small constraints)
**Clues:**
- n ≤ 100 or 200  
- try all pairs/triples  
- strings length small  

**Tool:** nested loops  

**Important:**  
Beginners avoid brute force TOO MUCH.  
But often it’s intended.  

---

## Pattern 7 — Simulation
**Clues:**
- turns  
- game  
- step by step  
- process operations  

**Tool:** loop + simulate  

**Example:**  
- Sereja and Dima  

---

## Pattern 8 — Math / Parity
**Clues:**
- even/odd  
- divisibility  
- mod  
- gcd  
- ceiling  

**Tool:**  
- `%`  
- `gcd`  
- `(x+y-1)//y`  

---

## Pattern 9 — Stack
**Clues:**
- remove adjacent  
- brackets  
- undo  
- nearest greater  

**Tool:** list as stack  

---

## Pattern 10 — Binary Search
**Clues:**
- minimize/maximize answer  
- monotonic condition  
- large constraints  

**Tool:** binary search on answer
